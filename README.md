# K. Vignesh — AI/ML Portfolio

A responsive portfolio website tailored using the details in K. Vignesh's supplied CV. Built with HTML, CSS, and JavaScript; no build step is required.

## Files
- `index.html` — portfolio homepage
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `cv.pdf` — CV linked from the website

## Before publishing
1. Check the CV details and publication status carefully.
2. Replace the generic LinkedIn and GitHub links in `index.html` with your real profile URLs.
3. Add public project repositories, Google Colab notebooks, demos, and screenshots where available.
4. Do not publish confidential employer data, proprietary code, or internal screenshots.
5. If you do not want your phone number or CV to be public, remove those details or remove `cv.pdf` before publishing.

## Preview locally
Open `index.html` in a browser. No packages are required.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `vignesh-ai-portfolio`.
2. Upload the contents of the `ai_ml_portfolio` folder to the repository root (not the outer folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for deployment. GitHub will show the public URL in Pages settings.

## Important
Project descriptions are based on the supplied CV. Add only public-safe evidence and verified links. Do not invent performance numbers or disclose confidential work.
